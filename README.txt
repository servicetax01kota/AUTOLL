CA AUDIT TOOL - local version (no database server needed)

TO RUN
1. Install Node.js (LTS) once from https://nodejs.org
2. Double-click run.bat
   - First run downloads packages (internet needed, a few minutes).
   - Browser opens at http://localhost:3000
3. Keep the black window open while working. Close it to stop.

YOUR DATA
Everything is stored in one file: data\audit.db
To back up, copy that file. To restore, put it back in the data folder.
